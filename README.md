# Ish Garg — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It is published at https://ish596.github.io/.

## Interactive features

- Animated local workflow simulation in the hero.
- Project filters and expandable case studies for five GitHub projects.
- Copy-email button and social links.
- Open Graph and Twitter metadata with a custom share preview image.

## Featured work

Vantara Customer Behavior Prediction Platform; HR Recruitment Screening Automation; AI Email Assistant; Sales Lead Qualification Automation; and OpsFlow Automation.

DSA with Java, FSD Assessment, and Mini Project 1 are intentionally not featured.

## Run locally

Open index.html in a browser. There is no build step.

## Update the site

Edit index.html for copy, project descriptions, skills, and contact details. Update assets when project screenshots change. If the site moves to a different domain, update the social URL metadata in index.html.
