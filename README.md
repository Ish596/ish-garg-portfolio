# Ish Garg — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It is published at https://ish596.github.io/.

## Featured work

- Vantara Customer Behavior Prediction Platform
- HR Recruitment Screening Automation
- AI Email Assistant
- Sales Lead Qualification Automation
- OpsFlow Automation

DSA with Java, FSD Assessment, and Mini Project 1 are intentionally not featured.

## Run locally

Open index.html in a browser. There is no build step.

## Update the site

Edit index.html for the intro, project descriptions, skills, and contact details. Replace project screenshots in assets as needed. The screenshot frames crop the n8n top and bottom interface bars in the page view.

Open Graph and Twitter metadata plus a social preview image are included for link previews. If the site moves to a different domain, update the canonical, social image, and URL metadata in index.html.
